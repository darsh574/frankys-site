Projects — Setup & Structure
Build the right foundation before you type a single prompt
5 tips
Naming
Use brand name as project name
Name each project after your brand or client. Keeps work clearly separated and easy to navigate.
+
Instructions
Add strict instructions per project
Set custom instructions inside each project so Claude always outputs in your preferred format, tone, and style.
+
⚠ Corrected Documents
Upload documents in project — with caution
They still count against your context/tokens each time the chat loads. Keep uploads lean and essential only.
+
One Chat
Stay inside one chat per project
Don't switch chats. A single continuous chat builds context and saves time — you won't need to re-explain brand details each session.
+
✦ New Memory
Enable memory in settings
Turn on the memory option in Claude settings. Claude will remember key details from your conversations over time.
+
2
Prompt Efficiency — Save Credits
Write less, get more. Every message costs — make it count
4 tips
Ask First
Add a question phase to prompts
Tell Claude to ask clarifying questions before generating. This avoids bad outputs and wastes no follow-up prompts.
+
Edit, don't re-prompt
Edit your prompt if output is wrong
If the output is off, edit the original prompt and regenerate — don't send a new message. Every new message costs credits.
+
Batch Questions
Ask everything in one message
Combine related questions into a single prompt instead of multiple back-and-forth messages. Fewer prompts = fewer credits used.
+
⚠ Corrected Lean Prompts
Skip useless filler in your prompts
Remove unnecessary filler and verbose descriptions. Keep messages tight and direct — only include what Claude actually needs.
+
3
Model Selection — Use the Right Tool
Pick the right model for the job and stretch your credits further
2 tips
Haiku Mode
Use Haiku for simple tasks
Claude Haiku is faster and uses fewer credits. Switch to it for lightweight, straightforward tasks to preserve your free-tier allowance.
+
⚠ Corrected ChatGPT
Use ChatGPT for low-value throwaway tasks
Use ChatGPT for low-priority tasks that don't need quality. Save Claude for analysis, writing, and anything where output quality matters.

Integrations — Claude Beyond the Chat
Use Claude everywhere you already work — no tab switching
4 tips
Chrome Extension
Claude in Chrome — ask from any page
Install the Claude Chrome extension. While browsing any site, open the sidebar and ask Claude directly — no tab switching needed.
+
Excel & PowerPoint
Claude in Excel and PowerPoint
Use Claude directly inside Excel and PowerPoint to write content, generate slides, analyze data, and format outputs without leaving the app.
+
Word Documents
Claude in Word
Claude works inside Word too — use it for drafting, editing, and structuring documents directly within the editor.
+
Visualizations
Ask Claude to visualize anything
Claude can generate charts, diagrams, flowcharts, and interactive visuals directly inside the chat — no separate tool needed.

Best Practices — Golden Rules
